## Task 1 — Create deterministic source/privacy audit tooling

Create `tools/check-m7-security-privacy.mjs` as a read-only scanner. It must exit non-zero on a proven prohibited pattern and print only safe file/path/category diagnostics, never matched secret values.

The scanner must cover repository-controlled source/test/config files while excluding dependency/build caches. It must detect or explicitly allowlist with justification:

- credential-bearing provider URL construction in log/error/DOM persistence paths;
- raw password/token/credential serialization into ordinary structured storage;
- new credential use of `localStorage` or ordinary IndexedDB;
- suspicious `console.log`, `console.info`, `console.debug`, `console.warn`, `console.error` calls in credential/provider/pairing boundaries;
- DOM `data-*` writes containing credential/payload/token/stream-url fields;
- obvious decrypted pairing payload logging/serialization;
- unsafe raw error serialization in secret-bearing boundaries.

Do not make the scanner flag type/interface field names merely because words such as `password` exist in a credential model. The violation is unsafe persistence/logging/exposure, not the existence of credential fields.

Run:

```bash
node tools/check-m7-security-privacy.mjs
```

If the frozen base violates a rule, preserve that exact scanner failure as RED before production edits.
